================================================================================
Workpulse - Cross-Platform Enterprise Desktop Agent (v2.0.2)
Master Architectural Points & Feature Highlights
Indovision Services
================================================================================

1. PYTHON / PYSIDE6 CROSS-PLATFORM ARCHITECTURE
   - Native desktop application built on Python 3.12 and PySide6 (Qt 6).
   - Fully cross-platform: Windows 10/11 x64 and macOS 12+ (Monterey through Sequoia).
   - High-performance, multithreaded architecture: Main GUI Thread, QThread Polling Worker,
     Screenshot Worker, Batch Sync Engine, and Auto-Update Worker.
   - Resource-efficient: < 1.0% average CPU overhead and < 85 MB RAM memory footprint.

2. DYNAMIC COMPANY BOOTSTRAP & SECURE AUTHENTICATION
   - Multi-tenant company verification via POST /appcontroller/appcontroller.
   - Dynamically resolves, locks, and caches tenant-specific Base URL, logo, and portal links.
   - Employee authentication via POST /login/login returning scoped credentials.
   - Session store in %LOCALAPPDATA%\Workpulse\data\session.json with complete multi-user isolation.

3. HARDWARE DEVICE ENROLLMENT & SCOPED TOKENS
   - Stable hardware identity generated from system motherboard / platform UUID.
   - Workstation enrollment via POST /workpulse/enroll_device returning dedicated device_token.
   - All subsequent workpulse, health telemetry, and screenshot payloads authenticated via device_token.

4. REAL-TIME ACTIVITY & PLATFORM-SPECIFIC IDLE TRACKING
   - Real-time active window polling via Win32 (GetForegroundWindow/GetWindowTextW) on Windows
     and PyObjC (NSWorkspace/Quartz) on macOS.
   - Smart Idle Engine: Preserves active application at the onset of user inactivity.
   - Idle Detection: GetLastInputInfo on Windows; CGEventSourceSecondsSinceLastEventType on macOS.
   - On resumption, commits exact active and idle metrics to local ACID SQLite storage.

5. LOCAL-FIRST OFFLINE QUEUE & VERIFIED SCREENSHOT CLEANUP
   - Local storage in %LOCALAPPDATA%\Workpulse\ (Windows) / ~/Library/Application Support/Workpulse/ (macOS):
     * data/        -> SQLite database (activity_tracker.db) with WAL mode & session.json
     * screenshots/ -> Local JPEG compressed screen captures (Quality 75)
     * logs/        -> Rotating diagnostic logs (activity_tracker.log)
     * updates/     -> Staged update installers and hidden updater runners
   - Zero data loss during network outages: Local SQLite queue holds pending activities and screenshots.
   - Transactional Batch Sync via POST /workpulse/save_activity_batch (up to 100 records / batch).
   - Verified Cleanup: Screenshot files are purged locally ONLY after server HTTP 200 confirmation.

6. DYNAMIC SYSTEM HEALTH TELEMETRY
   - Background telemetry collector (utils/system_health.py) sampling every 60 seconds:
     * CPU Usage (%) via psutil.cpu_percent
     * RAM Usage (%) via psutil.virtual_memory
     * Disk Usage (%) via psutil.disk_usage
     * Battery Level (%) & Charging State
     * Network Connectivity Status
   - Floating point precision stored internally; cleanly integer-rounded in API payloads.

7. ENTERPRISE DASHBOARD & HRMS INTEGRATION
   - Modern PySide6 Dashboard featuring:
     * Start Time Card (system start / workpulse initiation)
     * Today Total Time Card (accumulated active work duration)
     * Punch Time Card (first punch-in and last punch-out timestamps)
     * Attendance Status Badge (Present, Absent, Half Day, Holiday)
     * Real-time Sync & Update Status Indicators
     * Interactive Monthly Attendance Calendar (POST /attendance/get_attendance_record)
     * Dynamic Leave Quota Modal (POST /LeaveApply/view_balance)
     * KRA & Timesheet PMS Table with Inline Editing & Submission (POST /TaskPMS/fill_time_sheet)
     * One-Click Single Sign-On HRMS Portal Bridge with secure temporary auto-login bridge.

8. AUTHORITATIVE AUTO-UPDATE ENGINE & LOOP GUARD
   - Target version resolved strictly from live App Controller API response (POST /api/appcontroller/appcontroller).
   - Semantic numerical version precedence (server_version > installed_version).
   - Stream download with PE binary / Inno Setup signature validation (> 100 KB, 'MZ' header).
   - Detached silent Inno Setup installation via hidden VBScript (wscript.exe) / PowerShell runners.
   - Atomic state store with update loop guard: Max 2 failed attempts enters 24-hour cooldown.

9. AUTOMATED QUALITY ASSURANCE & MULTI-PLATFORM CI/CD
   - 295 automated unit and integration tests passing across all functional domains.
   - 100% test pass rate covering authentication, workpulse, sync, attendance, health, and auto-updates.
   - GitHub Actions CI/CD workflows (.github/workflows/release.yml, build-macos.yml) for automated
     PyInstaller executable generation, Inno Setup installer packaging, and macOS DMG builds.
